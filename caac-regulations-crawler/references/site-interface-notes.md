# 民航局站点接口逆向笔记

> **核实日期：2026-09-15。** 以下参数与选择器均对线上站点实测确认。
> 官网改版后脚本失效时，**先读这份**，逐项复核下面每一条。
>
> 复核方法：抓一个列表页原始 HTML，检查 `SECTIONS` 里的 channelid 是否仍能返回条目；
> 抓一个详情页，检查 `VAR_RE` 能否抠出 `buhao` / `youxiao`。两者任一失败即为改版。

## 1. 站点结构

信息公开栏目页面本身是**空壳**，真实列表由站群检索接口动态填充：

```
https://www.caac.gov.cn/was5/web/search?...
```

接口返回**纯 HTML 片段**，无 JS 渲染、无验证码、无登录要求。

## 2. 列表接口

### URL 形态

```
{HOST}/was5/web/search
  ?page={页码，从 1 开始}
  &channelid={栏目 ID}
  &was_custom_expr={URL 编码的检索表达式}
  &perpage={每页条数}
  &orderby=-fabuDate
  &divShow=wenhao
  &selST=All
  &selYouxiao={URL 编码的有效性}
  &fl={栏目 fl}
```

其中检索表达式（**必须 URL 编码**，注意首尾各有一个空格）：

```
 PARENTID='{fl}' or CLASSINFOID='{fl}' 
```

`was_custom_expr` 是必需参数——缺了它 `selYouxiao` 筛选不会生效。

### 参数取值

| 参数 | 值 | 说明 |
|---|---|---|
| `perpage` | `100` | 实测可用。默认 10，改 100 可把列表请求数从 200 余降到约 28 |
| `selYouxiao` | `有效` | 可选：`有效` / `失效` / `废止` / `历史版本` / `All` |
| `orderby` | `-fabuDate` | 按发布日期倒序 |

### 四个栏目

```python
SECTIONS = [
    ('法律法规',   '211383', '12'),
    ('民航规章',   '269689', '13'),
    ('规范性文件', '238066', '14'),
    ('标准规范',   '211383', '15'),
]
```

注意「法律法规」与「标准规范」**共用 channelid 211383**，靠 `fl` 区分。

### 实测档量（2026-09-15）

| 栏目 | 现行有效 | 全部（含失效/废止/历史版本） |
|---|---|---|
| 法律法规 | 47 | 47 |
| 民航规章 | 130 | 400 |
| 规范性文件 | 1357 | 1400+ |
| 标准规范 | 1152 | 1200+ |
| **合计** | **2686** | |

「末页」指示的页码数字**不可信**（All=400 与各状态相加对不上）。准确值需逐页走到空页为止。

### 列表项选择器

```python
ITEM_RE = re.compile(
    r'<a\s+href="(http://www.caac.gov.cn/XXGK/XXGK/[^"]+?t\d{8}_\d+\.html)"'
    r'[^>]*?name="([^"]*)"[^>]*>([^<]*)</a>', re.I)
```

标题取 `name` 属性，回退到锚文本。**注意站点返回的链接是 `http://`，需替换为 `HOST`（https）。**

列表页自带一个「有效性」筛选下拉框（选项：有效 / 失效 / 历史版本 / 废止），其翻页链接暴露了上述完整参数——这是逆向下手处。

## 3. 详情页

### URL 形态

```
{HOST}/XXGK/XXGK/{栏目路径}/YYYYMM/tYYYYMMDD_{id}.html
```

### 元数据字段

从页面内联 JS 变量读取：

```python
VAR_RE = re.compile(r'var\s+([A-Za-z_$][\w$]*)\s*=\s*"([^"]*)"')
```

| 变量名 | 含义 | 用途 |
|---|---|---|
| `buhao` | 部号（如 `CCAR-290-R4`） | 命名首字段 |
| `wenhao` | 文号（如 `交通运输部令2026年第14号`） | 命名尾字段 |
| `bwdw` | 发布单位 | 索引列 |
| `fwrq` | 成文日期 | 命名尾字段、索引列 |
| `youxiao` | 有效性 | **归档依据** |
| `weizhi001` | 子类 / 位置 | 索引列 |

### 正文容器

```python
CONTENT_RE = re.compile(r'<div class="content"\s+data-role="n_content"\s*>', re.I)
```

从中开标签起做**括号配对扫描**（跟踪 `<div>` 开合深度）取到闭合处，而非正则直接截断。

> 注意：约 145 条条目的正文承载在网页里（非 PDF），其中部分正文极短——官网只写了一句标准适用范围。

## 4. 附件

### 形态

相对路径，形如：

```html
<a href="./P020260717459628983882.pdf" target="_blank">通用航空经营管理规定（中华人民共和国交通运输部令2026年第14号）.pdf</a>
```

- **文件名是流水号，无意义。** 真名靠列表标题 + 元数据回填。
- **锚文本就是官方真实文件名**，可作为「官方原名」留档。

### ⚠️ 关键陷阱

**同一个文件名在页面里出现两次**：一次在真实的 `<a href>` 中，一次在**内联 JS 字符串**里：

```javascript
if(...){ ... }else if(t=0){ $("normWenHao").show(); ... h = "href=\"./P0....pdf\""; ... }
```

若正则只匹配 `href="..."` 而不锚定 `<a>` 标签，会命中 JS 那份，随后 `[^>]*?>` 一路吃到后面的 `>` 比较符，把 JS 代码当成锚文本——曾因此**静默污染 103 行索引数据**。

**正确写法**（锚定完整的 `<a ...>锚文本</a>`，对 JS 的转义引号形态天然不匹配）：

```python
ATT_RE = re.compile(
    r'<a\b[^>]*?href\s*=\s*["\'](?:\./)?(P\d+\.(?:pdf|doc|docx|xls|xlsx|zip|wps))["\']'
    r'[^>]*>\s*([^<]{0,220}?)\s*</a>', re.I)
```

另加 JS 噪声黑名单兜底：`('$(', 'function', 'var ', ');', '\\u', '</')`。

### 附件扩展名实际分布

实测 2686 条：`.pdf` 2318 / 无扩展名 204 / `.doc` 11 / `.zip` 5，另有 `.rar`、`.jpg` 各 1。

⚠️ **官网存在扩展名标错的情况**：17 个标 `.pdf` 的文件实际是：

| 文件头魔数 | 真实格式 | 数量 |
|---|---|---|
| `\xd0\xcf\x11\xe0\xa1\xb1\x1a\xe1` | OLE2 复合文档（`.doc` / `.xls`） | 12 |
| `PK\x03\x04` | ZIP（扫描件图片包，含 `001.jpg` …，单份最大 43 MB） | 5 |

需按魔数纠正扩展名，否则用户双击直接报错。

## 5. 有效性字段：不可信

**这是本项目最重要的一条实测结论。**

服务端 `selYouxiao=有效` 筛出的条目中，有 **781 条（29.1%）** 详情页 `youxiao` 字段写的是「失效」或「废止」：

| 栏目 | 冲突率 | 说明 |
|---|---|---|
| 民航规章 | **0%** | 服务端筛选准确 |
| 法律法规 | 4.3%（2 条） | 1980 年代老法规 |
| 标准规范 | 25% | 越早年越密集 |
| 规范性文件 | **36%** | 最严重 |

根因：AC/AP/MD 类文件被新版替代后，官网只更新了**详情页**状态，检索索引的 `selYouxiao` 字段未同步。

**处置原则**：服务端筛选只当粗筛；**最终归档依据用详情页 `youxiao`**。冲突件不删除，移入 `民航法规_已失效废止存档/` 保留，并在索引「对账」列标注。

另有约 2.3% 条目 `youxiao` 字段为空——这是页面编辑漏填，**随机分布**（PDF 与网页都有），不是某栏目天生缺此字段。脚本按"抠不到就不当废止处理"保守保留。

## 8. 改版应对

脚本已内置两道自检，失效时不会静默：

1. **列表第 1 页解析出 0 条** → 记入 `failures.jsonl` 并打 `!!` 告警（多半是 `SECTIONS` / `ITEM_RE` 失效）
2. **有效性缺失率 ≥ 30%** → 体检表判定"疑似官网模板变更，过滤结果不可信"

改版后的修复顺序：核对 `SECTIONS` 的 channelid → 核对 `was_custom_expr` 表达式 → 核对 `ITEM_RE` → 核对 `VAR_RE` 的字段名 → 核对 `CONTENT_RE` 容器。
